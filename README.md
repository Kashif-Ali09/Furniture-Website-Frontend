# PakFurni Frontend Demo

A responsive furniture-store frontend built with plain HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure
- `style.css` — layout, colors, responsive styling
- `script.js` — product cards, search, filters, demo cart, newsletter message

## Run locally
1. Extract this folder if downloaded as a ZIP.
2. Open `index.html` in a browser, or open the folder in Sublime Text and use **File → Open**.
3. An internet connection is needed to load the remote furniture photos and Google Fonts.

## Notes
- Product names and prices are sample data for a student/demo project.
- Cart and newsletter are frontend demonstrations; there is no payment system, backend, or actual email subscription.
- Product photos are loaded from Unsplash URLs, so no manual image downloads are needed. The images may require internet access and their URLs may change over time.
